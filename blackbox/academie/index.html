Commence ici : le plus petit CARO qui marche

Un Raccourci iPhone qui écoute ta question, l'envoie à Claude et lit la réponse à voix haute. Une soirée de travail, aucun serveur.

Ta clé API = ton portefeuilleQuiconque a ta clé peut dépenser sur ton compte. Ne la mets jamais sur GitHub, dans une capture d'écran ou dans un raccourci que tu partages. Si elle fuit, supprime-la dans la console et crées-en une autre.

  1. Crée ta clé API

    Va sur platform.claude.com, ajoute quelques dollars de crédit, puis crée une clé dans la section des clés API. Garde-la dans ton gestionnaire de mots de passe.

  2. Ouvre Raccourcis et crée « Hey Caro »

    Dans l'app Raccourcis, crée un nouveau raccourci et nomme-le Hey Caro. Siri le lancera quand tu diras « Dis Siri, Hey Caro ».

  3. Ajoute les actions dans cet ordre

    • Dicter le texte : CARO écoute ta question.
    • Obtenir le contenu de l'URL : URL https://api.anthropic.com/v1/messages, méthode POST.
    • Dans la même action, ajoute 3 en-têtes : x-api-key = ta clé, anthropic-version = 2023-06-01, content-type = application/json.
    • Corps de la requête : JSON, avec les champs ci-dessous. Remplace la valeur de content par la variable « Texte dicté ».
    // Corps JSON de la requête
{
  "model": "claude-opus-5-5",
  "max_tokens": 2048,
  "output_config": { "effort": "low" },
  "system": "Tu es CARO, l'assistant vocal de Black Box. Réponds en français québécois, en 3 phrases max, sans liste ni symbole : ta réponse sera lue à voix haute.",
  "messages": [
    { "role": "user", "content": "[Texte dicté]" }
  ]
}

  4. Lis la réponse à voix haute

    La réponse contient une liste content. Ce modèle réfléchit toujours un peu avant de répondre, alors cette liste commence par un bloc de réflexion (vide) suivi du bloc de texte. Il faut garder seulement le texte :

    • Obtenir la valeur du dictionnaire : clé content.
    • Répéter avec chaque élément de cette liste.
    • Dedans : Si la valeur de type est text, alors Énoncer le texte avec la valeur de text.

  5. Teste : « Dis Siri, Hey Caro »

    Demande-lui « c'est quoi un jeton? ». Si rien ne parle, ajoute Afficher le résultat juste après l'appel URL pour voir l'erreur. Une erreur 401 veut dire que la clé est mauvaise, une erreur 400 que le JSON a une faute.

Même chose en Python, pour le niveau 1 
# pip install anthropic
# La clé est lue dans la variable d'environnement ANTHROPIC_API_KEY
import anthropic

client = anthropic.Anthropic()

reponse = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=16000,
    system="Tu es CARO, l'assistant de Black Box. Réponds en français québécois.",
    messages=[{"role": "user", "content": "Salut Caro, t'es qui?"}],
)

for bloc in reponse.content:
    if bloc.type == "text":
        print(bloc.text)

print(reponse.usage.input_tokens, reponse.usage.output_tokens)  # ce que tu paies

Tu peux changer de modèle dans le JSON. claude-opus-5-5 est le plus fort pour l'usage courant. claude-haiku-5-5 coûte beaucoup moins cher et suffit pour des questions simples.
